# New-World-NeoForge
A small mod that adds a biome to the world. On NeoForge

For the Fabric version: https://github.com/ArshiaDPG/New-World-Fabric

Features:
- Wooded Meadows: Meadow variant with fir trees 
- Fir: New tree type which generates in wooded meadows and less commonly in taigas
- Loam: Block set, which generates in lush caves
- Buried Bunkers: Underground structure which generates in plains and meadows 
- Tombstone: A block which saves your items upon death if held in the inventory 
- Ancient Mattock: A multi-tool which can mine all other tool types can efficiently 
- Moss Sprouts: New decorative plant which can spawn in moss vegetation
- Farmer's Delight Integration: Fir cabinets
- No Man's Land Integration: Fir bookshelves and trimmed planks
